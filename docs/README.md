# OctoAcme Project Management Docs

OctoAcme uses a customer-first project management lifecycle that moves from initiation to planning, execution, release, and retrospective. Teams start with a lightweight project one-pager that clarifies the problem, goals, success metrics, stakeholders, timeline, and early risks before work is approved.

Once a project is underway, delivery is managed through a prioritized backlog, clear acceptance criteria, defined roles, and regular communication. Project Managers coordinate schedules, risks, and stakeholder updates; Product Managers prioritize outcomes and measure success; Developers and QA/Test partners build, validate, and refine work in small, reviewable increments.

Quality and alignment are reinforced throughout the lifecycle with project boards, small pull requests, CI checks, smoke testing, release readiness reviews, and retrospectives that turn lessons learned into tracked action items. Use the documents below as the starting point for onboarding, planning, and running OctoAcme projects consistently.
